# 订单查询说明

本文件只描述「怎么用已有工具」，不新增任何权限。

## 前提

- 只能查**当前登录用户自己**的订单。用户身份在工具构造时已绑定，
  不存在「查别人订单」这个能力，也没有对应参数可以传。
- 未登录用户不会加载订单工具。此时直接告知需要先登录，不要尝试绕过。

## 什么时候调用

| 用户表达 | 动作 |
|---|---|
| 我的订单、买过什么、那笔订单到哪了 | 调 `myOrders` |
| 怎么退货、多久发货、能不能开发票 | 不查订单，直接讲规则 |
| 帮别人查订单 | 拒绝，说明只能查本人 |

## 怎么讲

- 按时间倒序讲，最多列最近 5 笔，避免刷屏。
- 订单号用工具返回的展示形式，不拼接内部 ID。
- 状态用中文业务含义描述，不要把枚举值直接抛给用户。
- 金额只陈述，不判断该不该退、该不该赔。

## 禁止

- 不展示手机号、收货地址、支付流水号、身份证信息。
- 不代替用户发起退款、取消订单、修改地址。
- 工具报错或返回空时如实说明，不编造订单内容。
