# 一、家电安装相关知识

## 1、适用品类

大家电：电热水器、油烟机、燃气热水器、灶具、集成烹饪中心、洗碗机、空调、中央空调、洗衣机、洗烘套装、平板电视
家居类：实木床、衣柜、电视柜、皮艺沙发、实木沙发、皮艺床、布艺床、布艺沙发、沙发床、板式床、功能床、儿童床、功能沙发、板木床、皮布沙发、拔步床/架子床、办公桌、更衣柜、会议台/桌、书柜、茶桌/茶台、货架浴室柜、马桶、智能坐便器、淋浴房、衣柜、定制淋浴房、智能浴室柜、浴霸、板式床、实木床；
## 2、在线客服-安装信息及功能

- 服务类型：可判断是否为“送装一体”或“送装同步”；履约方识别：可判断是否为本商城服务家/商城安装服务；服务详情：可看到服务单现有的服务进度、工程师、网点、联系方式等；服务催促：发起限制：已派单至已完成/已取消的所有状态； 次数限制：最多可点击催促3次（当一条催促未处理完成前，不可以发起第二次催促，与用户本商城APP共用次数）； 处理时效：一般2小时内反馈；服务投诉：发起限制：已派单至已完成/已取消的30天内； 次数限制：最多可点击催促1次（与用户本商城APP共用次数）； 处理时效：一般24小时内反馈

## 3、用户APP-安装信息及功能

### 3.1 安装进度信息查看路径

1. 路径一：我的-我的订单-服务跟踪查询
2. 路径二：我的-我的订单-点击进入订单详情-服务跟踪查询
目前APP支持的功能有取消服务、修改预约时间、再次预约安装、投诉安装、催促安装；
1. 取消服务：生成安装服务单后，工程师上门前可申请取消
2. 修改预约时间：可对上门安装时间进行预约改约处理，操作次数上限为5次（需品牌履约商接入了此功能，是否可操作以系统页面为准）
3. 申请安装：用户取消安装服务后，可申请二次安装，1年内上次3次（会生成新的安装单，再次选择上门安装时间）
4. 投诉安装：在订单完成的情况下，从安装网点接单后，到安装完成后30天内可见
4.1. 反馈次数：最多可点击投诉1次；
5. 催促安装：在订单完成的情况下，从安装网点接单后到安装完成的时间段内可见。
5.1. 反馈次数：最多可点击催促3次（当一条催促未处理完成前，不可以发起第二次催促）；
### 3.3 履约方为商城安装服务，服务进度中包含内容

目前APP支持的功能有取消服务、修改服务、一键求助、联系客服、查看收费标准；
1. 取消服务：点击取消服务后，后续需要再次安装，再次申请服务；
2. 修改服务：支持修改服务时间、联系人姓名及电话;
3. 一键求助：点击一键求助支持反馈收费、送货、服务异常等问题；
4. 联系客服：点击联系客服跳转至服务+在线客服（也可通过：商城安装服务公众号—个人服务-咨询客服）
5. 查看收费标准：本商城安装费用说明详见【 根据商品品类确认费用，也可以通过关注商城安装服务公众号【商城安装服务，个人服务，收费标准】中查看服务+收费准则。
# 二、场景方案

## 场景一：如何预约安装？/什么时间给安装？

1. 通过安装服务识别客户订单是否为送装一体/送装同步订单；
1.1. 送装一体：告知客户无需预约，一般商品送到就会安装，建议客户耐心等待；
1.2. 送装同步：告知客户可以预约货到后3小时内的安装，安装师傅会根据客户期望的安装时间提前预约上门时间，建议客户耐心等待；
1.3. 非送装一体且非送装同步：判断履约方是否商城安装服务（家）
1.3.1. 非商城安装服务（家）：安装人员一般会在商品出库后2小时内联系客户进行首次预约，并在首次预约上门时间前一天会进行二次预约（确认是否调整时间）；
1.3.2. 商城安装服务（家）：安装人员一般会在商品出库后2小时内联系客户进行首次预约，并在商品妥投后2小时内进行二次预约（确认是否调整时间）；
## 场景二：安装额外收费吗？

- 处理方案：参考商详、厂家政策及安装信息服务费解答；
## 场景三：催促安装（已下单）

1. 通过订单特殊标记识别客户订单是否为送装一体/送装同步订单
1.1. 送装一体/送装同步：告知客户商品送到就会安装，建议客户耐心等待，参考催单方案处理；
1.2. 非送装一体且非送装同步：告知正常时效，如果用户反馈无人联系/不认可时效，核对是否有分配工程师；
1.2.1. 如有分配工程师，告知工程师联系方式，建议联系工程师沟通协商；
1.2.2. 如未分配工程师或用户不愿联系，可代用户发起“服务催促”；
## 场景四：更改安装（时间、地址等）

1. 判断是否为送装一体/送装同步订单
1.1. 送装一体/送装同步订单：按修改订单配送时间处理，不支持妥投后再次安装
2. 非送装一体且非送装同步：判断履约方
2.1. 厂家服务商 ：厂家内部对接联系处理；
2.2. 商城安装服务（家）：引导客户通过订单详情页/“商城安装服务"公众号进行操作（路径：订单详情页-安装服务进度-修改服务）；
2.3. 商城自营安装（仅限空调）：  引导客户通过订单详情页操作（路径：订单详情页-安装服务进度-修改服务）；
## 场景五：取消安装

1. 判断订单是否为送装一体/送装同步订单
1.1. 送装一体/送装同步订单：按取消订单处理，不支持单独取消安装服务（或用户到货后自行联系安装）；
1.2. 非送装一体且非送装同步：判断履约方
1.2.1. 厂家服务商：建议客户自助取消或者商家内部代联系取消；
1.2.2. 商城安装服务（家）：
1.2.2.1. 取消安装服务：引导客户自助取消，取消操作路径为我的-我的订单-服务详情
1.2.2.2. 取消并退款：需要联系商详页商城安装服务在线客服或热线400-610-3600（热线服务时间：9:00-21:00）
1.2.3. 商城自营安装（仅限空调）：本商城App-我的-找到取消安装的商品订单-点击“服务跟踪查询”-点击“取消服务”
## 场景六：投诉安装多收费（家电家居）

请客户提供收费凭证，优先对照商品详情页收费标准及客户收费项，出现以下情况：
1. 如明确未多收费，需要与客户解释；
2. 如可判定多收费，可通过“服务投诉”发起投诉，根据反馈结果回复用户（时效一般24小时内）；
## 场景七：投诉安装师傅态度/投诉安装导致家中商品损失/安装后商品无法使用

- 可通过“服务投诉”发起投诉，根据反馈结果回复用户（时效一般24小时内）；
## 场景八：索要安装发票(商城安装服务 )

如客户咨询发票相关问题，优先引导客户通过“商城安装服务”公众号/小程序查看
1. 账单及发票查询
1.1. 进入商城安装服务公众号，在输入栏输入“发票”或“材配服务费”，点击提示文字进入列表页，可看到主商品和支付订单，点击支付订单进入详情页，即看到收款明细和2个按钮：查看发票、重开发票。
1.2. 进入商城安装服务小程序，点右下角我的，进入订单列表页，点击订单进入详情页，后续操作与公众号一致。
2. 开发票步骤
2.1. 电子普通发票：若个人抬头，直接点击查看发票，进入下载页面；若修改抬头，先点击重开发票，修改单位信息后退出详情页，再次进入详情页后点击查看发票，即可下载新发票；
2.2. 增税专票：点重开发票，填写发票信息后，点确定，由本商城票据中心3-5个工作日邮寄纸质发票，纸质的专票开具后，不可自助修改重开，如需重新开具，必须寄回原发票，报集团运营请票据中心线下重开。
# 三、常见场景话术（送装一体）

- Q1：送装一体服务是什么服务？
  - A1：送装一体服务是本商城联合各大品牌厂家共同推出的针对本商城用户购买支持送装一体的商品后，进行送货上门和安装一体化的升级服务，物流人员上门配送商品后根据客户需求可直接进行安装和调试服务。
- Q2：送装一体服务还需要额外支付费用吗？
  - A2：送装一体是不收费的，因安装环境不同，安装过程中可能出现额外辅材及其他服务，此部分辅材和服务需要收费，服务商将按收费标准收取费用，具体项目及费用以与服务商或品牌沟通为准。
- Q3：送装一体服务全国都可以覆盖么？
  - A3：您好，该服务具体覆盖范围请以下单页面为准。
- Q4：我购买的XXX赠送了送装一体服务，但是我没有安装可以退款么？
  - A4：您好，该服务为赠品，不支持单独退款。
- Q5：因客户环境问题（非本商城原因）无法送货上门（如上述情形，将不承担未履行“送装一体”的责任），商品应该如何处置？
  - A5：您好，因安装环境不允许，无法送货上门，建议您拒收商品，我们配送师傅会将商品退回，您的订单为您处理退款。
