# 一、场景说明

用户订单已签收/已完成，表示商品出现问题要求售后。
# 二、处理思路

## 通用处理思路：

1. 确认订单状态及商品签收状态及用户诉求；
2. 判断用户售后诉求判断是否符合售后政策；
a. 如符合售后政策，根据信息核对标准确认信息后代客户操作提交，并告知预计审核时效；
b. 如不符合售后政策，积极解释不符合原因并婉拒客户诉求；
## 核实及操作步骤：

1. 探索客户需求，定位客户问题点
a. 明确客户售后具体诉求点（退货/换货/维修等）及原因，并根据客户诉求判断商品状态及是否符合售后政策。
2. 了解订单商品的状态，判断是否符合售后政策，并给出对应的方案。(参考前台页面中的自营及第三方售后服务政策，判断客户所购买商品是否符合相关售后服务)。    售后政策介绍
a. 不符合售后政策：积极解释不符合原因，婉拒并安抚客户（明确不符合售后政策禁止代提交服务单）。
i. 已超过售后周期：优先婉拒用户，如商家客服判断可特殊给用户售后，可代客提交超期售后服务单    【对外版】自营商家在线客服代超期售后申请功能介绍
1. 商家提交后，平台会默认商家认可可特殊同意此售后，请商家谨慎使用此功能；
2. 超期售后仅代表可以提交售后，平台不卡控售后政策期限，但商品本身仍需按售后政策要求处理（例如质量问题退货，原来是7天内有质量问题可退，超期售后是提交后不卡控签收7天，但仍需要确认有质量问题可退）；
3. 极少数商品点击售后申请后，无法进行超期售后代申请，则说明此商品暂不支持在在线客服进行超期售后代申请（此情况不支持商家通过售后单处理，如商家基于体验特殊处理，可通过其他方式协商补偿，原因是商家合同售后政策不支持，如果此商品需要有超期售后权限，需联系采销更改售后退供政策）；
4. 可通过商品详情页-售后保障查看售后质保期，如无质保期的按照7退15换进行质保；（如存在整机与零部件质保期不一致问题，按最长质保期计算售后周期）
ii. 不符合售后要求：通过商品详情页查看商品售后政策是否支持七无、特殊场景是否有说明不属于质量问题；
iii. 人为损坏：以客户描述为主，如客户描述无法确认是否人损，可发送售后单提交；
- 特殊场景：
- 商品维修后需保证客户使用30天，如因售后维修处理过程中导致的商品超质保周期，且商品维修后在30天内在次出现问题，可代客户提交服务单；
- 如客户不符合平台售后政策，但商家可特殊处理，请明确告知用户是否可特殊处理，及处理方式（线上或线下）；
- 如用户界面有如下提示，建议严格按商城政策处理，不建议商家特殊处理；
b. 符合售后政策，代客户提交服务单操作：
i. 操作注意事项：
1. 需与客户确认订单数量及需要售后的数量，以及是否有绑定的赠品被拆单，保证客户需售后商品全部提交完毕；
2. 与客户确认商品描述（提交理由、描述，是否有发票，包装是否完整，并核对商品相关附件情况）；
3. 与客户确认预期服务方式（含售后类型、返件方式等）；
注：如明确客户诉求无法满足（如商品不支持上门换新，但客户要求必须上门换新且沟通无法达成一致），婉拒用户；
4. 与客户确认取件信息（客户地址，预期的取件方式，手机号，预约取件时间）；
路径：客服工作台-客服助手-订单详情页-售后申请
注：若点击售后申请后，无法进行超期售后代申请，则说明此商品暂不支持在在线客服进行超期售后代申请，建议商家与客户沟通用其他方式处理问题。

3. 提交后提醒客户注意事项
a. 告知客户服务单预计审核时效，引导客户在前台“我的--退换/售后--处理中”中查看审核意见及处理跟踪信息；
b. 提醒客户后期可自行前台提交服务单 ；
# 三、常见问题

- Q：如何申请售后。
  - A：点击我的>全部订单>对应订单>退换/售后，填写售后信息后，即可提交，提交成功后请耐心等待，由专业的售后工作人员受理您的申请。
- Q：为什么申请不了退货/换货/维修？（超售后期且不支持售后）
  - A：非常抱歉，可申请的售后服务以页面显示为准，如果订单超出了售后申请时间是无法申请的；
- Q：多次维修未修好怎么办？
  - A：法定三包目录范围内的商品，在售后周期内（部分要求在整机三包有效期内），如因商品质量问题维修两次及以上仍不能正常使用，凭借修理记录和证明，可为客户调换同型号同规格的产品（两次维修不限于同一问题，商品本身出现两次问题即可）。
- Q：售后质保期怎么计算？
  - A：自商品签收次日起开始计算售后质保期。（安装类商品质保期从安装之日起计算，24年7月1号之后安装的商品按此规则执行，之前安装的商品按签收次日开始计算）
- Q：赠品是否支持售后？
  - A：因赠品为赠送给客户的，赠品不支持单独退货，但是从签收次日起计算质保期，可支持质保期内质量问题换货和维修。
