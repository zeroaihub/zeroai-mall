# 二、售后质保期

1. 安装类商品质保期
1.1. 背景
《消费者权益保护法》于2024年7月1日起施行，对安装类目三包期限做出了新的规定，安装类商品：有效期限自商品安装完成之日起计算。（完成之日起计算即不论安装时间点，安装当天即为售后周期开始的第1天）
1.2. 规则说明
- 安装完成日期起计算，商品申请售后在质保周期内（包含退、换、修周期），客户可直接通过入口申请售后；安装完成日期起计算，商品申请售后已超质保周期（包含退、换、修周期），系统提醒客户已超服务周期无法申请售后。
- 特殊情况：如同订单同SKU多个商品多个安装时效（一个订单买了三台相同空调分别在不同时间安装）系统无法精准获取安装时间：商品安装时效优先按照系统内最早时间取；
- 安装类商品换新售后质保期：换新后商品按照新订单售后政策执行，质保期依旧按照安装完成之日起计算；
- 安装信息展示页面：通过在线客服订单页“安装信息”查询    家电家居安装
1.3. 常见问题：
- Q：安装类商品的特色服务（如30-30-180、只换不修等）是按收货时间计算还是安装时间计算，购买延保商品如何计算质保期？
- A：您好，特色服务需按照商品签收次日计算售后周期，延保商品按照售后政策执行。
- Q：安装类商品7天无理由从哪天开始计算？
- A：您好，从签收次日开始计算。
- Q：6月25日购买，7月5日安装是否享受安装以后开始算质保期？
- A：在7月5日安装质保期可按照安装完成之日起计算。
- Q：商品支持“7天无理由退货”，签收7天内客户完成安装，是否可给予7无处理？
- A：您好，7无退货需保证商品完好，不影响二次销售，商品安装后不符合此要求，故安装后不支持7无。
2. 非安装类商品质保期
2.1. 消保法中关于质保期的规定
第十八条　经营者与消费者约定承担退货、更换、修理等义务的有效期限不得低于国家有关规定的要求。有效期限自经营者向消费者交付商品或者提供服务完结之日起计算，需要经营者另行安装的商品，有效期限自商品安装完成之日起计算。经营者向消费者履行更换义务后，承担更换、修理等义务的有效期限自更换完成之日起重新计算。经营者修理的时间不计入上述有效期限。
经营者依照国家有关规定或者与消费者约定履行退货义务的，应当按照发票等购货凭证或者服务单据上显示的价格一次性退清相关款项。经营者能够证明消费者实际支付的价格与发票等购货凭证或者服务单据上显示的价格不一致的，按照消费者实际支付的价格退清相关款项。

- 新订单质保期计算逻辑：三包规定内的商品，如换货周期内处理的换新，换新订单自新订单签收次日起重新计算质保周期，但不支持7无退货；如使用增值服务如90天只换不修、180天只换不修导致的换新，新订单支持重新计算质保期，但仅支持换货和维修，不支持退货（包括无理由退货和质量问题退货）

# 三、7天无理由政策

## 3.1.定义

消费者在本商城购物，选购带有“7天无理由退货”标识的商品，自消费者签收商品之日起7个自然日内（自消费者签收商品的次日开始起算）若产生退货意向且商品符合完好标准的，可进行7天无理由退货申请。
## 3.2.商品完好说明

商品完好指商品能够保持原有的品质和功能，商品本身、配（附）件（包含商标吊牌、使用说明书等）、商标标识等齐全。消费者基于查验需要而打开商品包装，或者为确认商品的品质、功能而进行合理的调试不影响商品的完好。对超出查验和确认商品品质、功能需要而使用商品，导致商品价值贬损较大的，视为商品不完好。
## 3.3.七天无理由退货商品类型

具体商品是否支持“7天无理由退货”以商品详情页展示为准。

# 四、退换修政策

## 4.1.能否退货

需同时满足：
1. 退货周期内（正常为7天，特殊商品退货周期以商品详情页为准，如商品售后政策显示为支持30天质量问题退货，则退货周期就是30天）；
2. 质量问题/本商城原因问题属实，针对物流损、少件、发错货等需按照现有标准核实责任方且在反馈时效内的；
3. 商品无人损且在国家三包范围内，人损指非质量问题导致的商品故障，如意外跌落、进水等，具体以工程师反馈结果为准。（如需无理由退货，需满足无理由退货条件）
特殊场景：
- 超过退货范围商家/采销同意退货，且有商家/采销明确可退的沟通记录；
- 审核人已备注做出特殊处理的，参考服务单留言进行解答。

- 客户换货原因：客责；是否支持换货：不支持换货

需同时满足：
1. 换货周期内（特殊商品换货周期以商品详情页为准）；
2. 质量问题/本商城原因问题属实，针对物流损、少件、发错货等需按照现有标准核实责任方且在反馈时效内的；

- Q：享受只换不修的换新订单还可以享受只换不修吗？

# 七、特色服务--随心换

## 7.1.服务介绍

随心换服务是为本商城用户提供的特色售后服务，客户针对在售后服务单申请页面带有“随心换”服务标识的部分自营商品提交换货申请时，可自助提交更换同款商品的相同或不同颜色、尺码等申请，换货申请符合条件的，在申请审核通过后，为客户更换新品。
## 7.2.申请路径

- PC端：客户服务-售后服务-返修/退换货申请-申请-选择服务类型“换货”；
- APP端：我的-退换/售后-申请售后-选择服务类型“换货”
## 7.3.服务特别说明

1. 随心换仅提供服务链路，不具备附加服务权益，服务单审核均需遵照平台、品类服务细则；
2. C端“随心换”服务标签已与2023年下线，不再对用户透传，线上已不存在独立的“随心换”售后类型；
3. 随心换服务不支持更换不同商品，仅支持因选错尺码、颜色不合适或商品质量问题等原因产生的换货需求，客户可自助选择更换同款不同颜色、尺码的商品等；
4. 因选择尺码、颜色不合适等客户原因需换货的，需保持商品的完好，商品未经穿着洗涤、无污垢、无损坏、吊牌未摘、附件齐全等，如不符合商品完好标准，则商品无法享受换货服务；
5. 原订单换新后生成的新订单不再享受“随心换”服务，如在换货周期内因商品质量问题有换货需求可申请换货服务；
