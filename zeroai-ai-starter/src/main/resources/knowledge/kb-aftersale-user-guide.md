# 一、场景描述

本文主要介绍售后前台（即客户端）系统功能，包含申请入口、审核/处理进度、退款查询、服务单评价等功能。
# 二、客户端申请入口

## 1、申请入口

### APP端

1. 我的--退换/售后
2. 订单列表页：我的--全部订单--退换/售后
3. 订单详情页--申请售后or订单详情页--退换/售后
4. 我的--客户服务--退换/售后
5. 消息中心--退换/售后
### PC端

我的--返修退换货
## 2、申请入口展示

- 按钮名称：退货入口；功能说明：根据三包的退货政策，默认展示7天，如商品打标30天退货，则申请入口展示30天，按最长的时效来展示
- 按钮名称：换货入口；功能说明：根据三包的换货政策，默认展示15天
- 按钮名称：自助选商品能力；功能说明：商城自营模式下部分商品在主站APP、PC、小程序端口开放用户申请换货时自助选择同SPU下同价商品。具体可更换商品以页面显示为准。
- 按钮名称：维修入口；功能说明：与商品质保期进行关联，维修入口展示时间周期与该商品质保期周期一致。
- 按钮名称：质保期外付费维修入口；功能说明：针对部分品牌做试点运行；客户支付完上门检测费用后，系统会安排工程师上门检测及维修，服务报告、收费明细等履约进度信息会透传到前台客户可见
- 按钮名称：补发商品入口；功能说明：针对手机贴膜品类订单，打标‘贴坏包赔’标签的将露出【补发商品】服务入口，且该服务标签限制一个订单仅可申请一次贴坏补发
- 按钮名称：协商留用；功能说明：在商品质保期内，根据用户属性、品类特性露出，一旦露出规则无法更改，如客户不接受可正常售后退换修

# 三、售后前台自助按钮

- 按钮名称：修改服务单；业务注释：修改服务单信息，包含地址、电话、处理方式、取件时间等，具体路径为：我的--退换/售后--处理中列表
- 按钮名称：催一下；业务注释：催促服务单审核（①工作时间内服务单提交后20分钟可催②待客服再次联系，超预约回电时间可催③待厂商反馈及待本商城反馈，超承诺反馈时间可催）
- 按钮名称：填写发货单；业务注释：客户自寄需客户自行填写发货运单信息
- 按钮名称：补充信息；业务注释：如缺失信息需客户补充，客户前台可实现自助上传
- 按钮名称：更改发货单；业务注释：如客户自寄出现运单信息填写错误，客户可自行更改
- 按钮名称：取消服务单；业务注释：如客户不想售后，可前台自行取消
- 按钮名称：催取件；业务注释：超预约取件时间未取件，可点击催促取件
- 按钮名称：取件评价；业务注释：针对上门取件的服务单，如取件完成，客户可针对取件服务进行评价
- 按钮名称：去评价；业务注释：服务单已完结，客户可点击进行评价
- 按钮名称：去支付；业务注释：如服务单已闪电退款，客户不退，可自行支付已退货款
- 按钮名称：已解决/未解决；业务注释：客户进行服务单评价的时候，如问题未解决，可选择未解决并留言
- 按钮名称：联系客服；业务注释：针对已超质保期的商品，前台展示联系客服按钮，可联系商家客服咨询
- 按钮名称：交易纠纷/纠纷进度；业务注释：申请交易纠纷，或者针对已申请的纠纷单查询处理进度
- 按钮名称：再次申请；业务注释：针对已取消或者非退换售后的商品可再次申请售后服务单
- 按钮名称：删除服务单；业务注释：服务单已完结，客户需删除服务单展示，可在我的-退换/售后--申请记录中找到对应的服务单并进行删除
- 按钮名称：卖了换钱；业务注释：商品已超出售后周期，客户可在服务单列表页选择“卖了换钱 ”，商品可在转卖平台进行闲置换钱
