# 一、场景描述

用户进线咨询售后服务单退款金额少于预期时的解释与处理口径。

# 二、处理思路

先查询退款明细，确认具体扣款项，再按扣款原因逐条向用户解释；不要笼统回答「系统自动计算」。
退款明细可在客服助手的服务单详情中查询（退款金额总计、退款明细）。

# 三、常见扣款原因

1. 误购取件费：用户申请无理由或误购退货，在无运费险、无免费上门退换权益时，按商品类别收取取件运费，按上门取件运费标准解释。
2. 赔付前置：申请售后前已发生过货款类赔付，先查赔付记录，说明对应款项与赔付原因。
3. 手工调整：审核人员与用户沟通一致后扣除部分款项（如折价退），以服务单留言为准解释。
4. 正向运费：下单时支付了运费，因用户原因（无理由、误购等）退货退款时需扣除正向运费。
5. 赠品费用：订单含赠品，仅申请主品退款时会扣除赠品费用；赠品也需售后时，可单独提交赠品售后。
6. 磨损费：商品存在磨损但给予特殊退货，经沟通一致可扣除一定费用。
7. 税点：退款时未提供原纸质发票，按一定比例扣除发票赔偿款。
8. 价保扣回：退货前申请过价保且已生效，退款时扣回价保金额，可通过客服助手查询价保信息。
9. 生鲜折损：生鲜商品存在化冻、损坏，用户在前台选择问题比例后，按比例扣除后退款。

# 四、常见问题

Q：用户反馈退款少了，且退款明细里能看到扣款原因。

A：经核实，您的售后服务单因 XXX 原因少退款，还请您理解。

Q：用户反馈退款少了，但查不到扣款原因或原因不明确。

A：很抱歉出现这样的问题，请您别着急，我帮您联系相关同事核实后答复，请您耐心等待。

# 五、边界

- 不承诺补退差额，也不自行计算应退金额，金额以退款明细为准。
- 扣款争议无法用明细解释时，转人工复核，不臆测原因。
