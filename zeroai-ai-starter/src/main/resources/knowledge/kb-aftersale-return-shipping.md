# 一、运费规则

备注：
1. 奢侈品客责场景，可免费为客户取件；如客户要求发货，可参考帮助中心《 退换货运费补偿标准 》进行补偿。
2. 客责售后退款时，售后系统会自动扣正向运费和上门取件费（ 取件费标准 ）；
- 在售后系统-退款明细中：
  - 【误购取件费】指的是售后取件费用（如果售后类型是换新/上门换新，取件费在换新订单交付的时候收取），收取时间参考： 退换货运费收取额度是多少？ ；
  - 【财务扣运费】指的是扣除正向运费；
- 注意
  - 财务扣运费：指的是客户购买商品时支付了运费，如果是因客责的原因申请服务单的情况，那么在售后退款时不会把正向运费退给客户，用户会看到收到的退款小于自己支付的金额。非客责原因的服务单，退款时不会扣除正向运费。
- 举例说明：客户购买了100元的商品同时支付了6元运费，在客户角度是总计支付了106元。在售后退款时，假设没有任何其他扣费项目且申请原因是客责（七无、误购等等），客户也只能收到100元退款，客户支付的6元正向运费是不会退给客户的。
  - 常用话术-扣除正向运费场景：尊敬的客户您好，订单运费，在售后退款时无法退还，会从退款中扣减。给您带来不便，请您谅解
  - 常用话术-扣除取件费场景：尊敬的客户您好，售后服务单退款时会从退款中扣减售后取件费用，给您带来不便，请您谅解
# 二、商品返件方式

1. 上门取件：商城自营配送范围内可安排上门取件，具体请以提交服务单为准
2. 客户发货：超出取件范围的需要客户在服务单审核后邮寄，并在7天内将快递单号填写至服务单，由客户先行垫付发货运费（禁止发到付件）——是否可赔付，参考上个板块运费规则；
- 常用话术-客户发货运费说明：
  - 尊敬的客户您好，商品通过快递方式返回本商城时，如本商城承担运费，商品寄回时需要您先垫付运费，售后服务完成后，将按照《退换货逆向运费补偿标准》（  ），以原支付方式进行返还（该标准仅适用于收货地址在中国大陆区域的，暂不包含港澳台区域）。给您带来不便，请您谅解。
3. 客户送货（仅限自营）：客户购买的商品符合售后退换货政策，如客户不方便本商城安排上门取件，可以在服务单审核后7天内自行送到就近的自提点，不收取上门取件费用（如有）；
3.1. 注意点
3.1.1. 自提点和物流配送站点是不一样的，不可引导客户将商品送到配送站点，自提点的地址可以在本商城首页查询链接（使用搜索关键词：自提点）：
3.1.2. 自提柜不接收售后返回商品；
3.1.3. 校园自提点可以收取售后退换返修商品；
3.1.4. 大家电类商品、微波炉、饮水机不支持送自提点，可以支持上门取件，具体以客户提交服务单为准。
3.2. 常用话术-客户送货运费说明：
3.2.1. 尊敬的客户您好，如果您自行将商品送至自提点，是不收取物流费用的。送货地点查询
