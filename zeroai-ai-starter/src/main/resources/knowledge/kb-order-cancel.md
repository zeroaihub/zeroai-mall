# 一、场景说明

用户已下单订单状态未签收，反馈要求取消订单。
# 二、通用诊断思路

1. 判断订单是否支持取消订单（已签收/已完成&生鲜订单不支持）
2. 咨询客户订单需取消原因，进行挽留。
3. 挽留失败，提醒用户取消后无法恢复，发送取消订单卡片（用户点击后进入订单详情页申请退款）；
- 注意：
  - 生鲜不支持取消订单，无取消订单入口，告知用户生鲜商品不支持取消，需婉拒用户；
参考话术：生鲜商品属于鲜活易腐类特殊商品，在订单商品出库后是不支持无理由取消订单的，给您带来不便请您谅解，同时您在商品签收时可开箱验货，如出现质量问题，我们也会有完善的售后服务，请您放心！

  - 预售订单优先告知客户预售规则中已经明确说明非本商城或商家责任导致的交易未完成的，定金不予退回，引导客户正常签收。
  - 生鲜订单不支持取消，需婉拒客户。
- 参考话术：生鲜商品属于鲜活易腐类特殊商品，在订单商品出库后是不支持无理由取消订单的，给您带来不便请您谅解，同时您在商品签收时可开箱验货，如出现质量问题，我们也会有完善的售后服务，请您放心！
# 二、取消订单相关说明

1. 订单已删除，订单已完成、已妥投，已签收，有正在处理中的售后服务单，有已完成的售后服务单（不含安装服务），有取消订单纠纷单以及已通过赔付全额退款的订单不支持取消订单
2. 部分子单取消剩余订单金额不满足运费标准，需扣除运费金额。
3. 订单含有“含赠品主订单”标记时，如注对应的赠品订单已完成则不支持取消，引导客户签收走售后。
4. 并非所有订单均支持部分退，以系统是否可以选择为准。
- 常见不支持部分退原因：
  - 主赠/买赠/满赠场景：赠品不可单独申请，申请主品时会自动携带赠品一同申请。
  - 加价购场景：主品发起部分退款时，若加价购商品满足特定条件，则主品和加价商品会联动一同申请；若不满足，则主品和加价商品支持单独退。
  - 延保商品/不可拆附件/礼品购场景：用户在选定主品后，页面会提示告知用户，需对此类商品联动提交退款申请，不支持单独提交。
# 三、常见问题

- Q：怎么取消订单？
- A：判断用户订单状态，给出相应的话术。
  - 未出库：您好，您可以自行申请取消订单，如页面没有申请退款按钮，代表不可以申请取消呢
  - 已输出：您好，您可以申请取消订单，申请后系统会拦截快递，可能存出现拦截不成功，快递员配送时您可以拒收，如页面没有申请退款按钮，代表不可以申请取消呢
注：客服需同步发送取消订单卡片
- Q：退款时效是多久呢？
  - A：您好，退款时效根据不同的付款方式退款时效不一致：
- 使用银行卡支付的退款时效，通常情况为1-3个工作日。特殊情况借记卡为1-7个工作日，信用卡1-15个工作日，请您耐心等待。
- 使用小金库付款，退款时效为1-2个工作日；
- 使用膨胀金付款，退款时效为1-5个工作日，如您使用膨胀金与其他支付工具组合支付，其他付款工具的退款时效以其他付款工具为准。
- Q：取消订单本商城优惠券会不会返还？
- A：您好，订单取消成功后会按原有效期自动返还优惠券，如优惠券在多个订单使用，需要所有订单都退款成功后返还。
- Q：取消订单本商城支付券会不会退回？
- A：若未支付成功时取消订单，会退回支付优惠券；若已支付成功后退货退款，支付优惠券是否退回，请以当时领取支付券的活动规则为准。您可 点击： ，选择对应优惠券，点击【查看使用】，在【详细说明】处查看优惠券的使用说明，如下图：

  - A：我们暂不支持撤销您的取消订单申请。您可以在订单详情页查看是否有撤销申请，如有可以点击申请撤销取消订单申请，撤销后会进行审核。能否撤销成功以实际配送结果为准~
- Q：生鲜出库了要求取消订单怎么办？
  - A：生鲜商品属于鲜活易腐类特殊商品，在订单商品出库后是不支持无理由取消订单的，给您带来不便请您谅解，同时您在商品签收时可开箱验货，如出现质量问题，我们也会有完善的售后服务，请您放心！
- Q：我现在取消订单怎么还收取我的运费呢？
  - A：拆单后，取消/拒收部分子单，系统会针对剩余子单重新计算运费，若多收则退还，少收则在取消订单时收取需要抵扣的运费金额，您可以在取消订单时自由的选择支付方式，如资产不充足将联动取消剩余子单。
