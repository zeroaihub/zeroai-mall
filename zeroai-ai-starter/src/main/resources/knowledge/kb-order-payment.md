下单流程：商品加入购物车 → 在购物车勾选要买的商品 → 去结算 → 选择收货地址和可用优惠券 → 提交订单 → 支付。

下单只结算购物车里「已勾选」的商品，未勾选的商品不进入订单；购物车一件都没勾选时无法提交订单。

订单金额口径：商品金额 + 运费 - 优惠券抵扣 = 实付金额。金额由服务端按同一份购物车快照计算，
页面显示的金额与落库金额一致，不要以手工估算的金额为准。

订单提交失败不会产生订单，也不会扣减库存。库存以提交订单时的服务端校验为准，
商品在结算过程中被抢完时，会提示库存不足而不是超卖下单。

未支付订单会超时自动取消，超时时长由部署配置（未支付订单超时时间）决定，当前部署配置为 1 分钟。
订单被自动取消后需要重新下单，原订单不能继续支付；因此在收银台停留过久会导致订单失效。

订单状态依次为：未付款 → 已付款 → 已发货 → 用户收货；另有申请退款、退款成功、用户取消、系统取消等状态。
确认收货后订单不能再撤销，操作前请确认已经收到商品。

支付在下单后调用收银台预支付接口完成，具体可用支付方式以收银台页面为准。
支付结果以支付渠道回调为准，页面短暂显示未支付时可稍后刷新订单状态。
